# P+F Svadba — Wedding Website

Source for the wedding website, hosted via GitHub Pages.

- `index.html` — the site root. Clean on-brand placeholder for now; the real
  wedding site gets built here (composed from the Notion source per the
  Notion CMS spec).
- `sampler/index.html` — the earlier font/color test page (canonical token
  reference: Sansita 700 headings, Encode Sans Condensed 300 body / 900
  accents). Lives at `/P-F-Svadba-VIP/sampler/`.
- `assets/img/` — art assets (heroes, motifs, palettes, landscape, mood scans).
- `robots.txt` — blocks search engine indexing. The link is meant for invited
  guests only, not public discovery.

Not indexed, not password-protected — just kept off search engines and shared
only via direct link.
